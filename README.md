# 🛒 E-Commerce Web Application

A modern, responsive, and full-featured E-Commerce platform built with Next.js and TypeScript.

🌐 **Live Demo:** [Click here to view the project](https://fresh-cart-e-commerce-sand.vercel.app/)

---

## ✨ Features
- **Authentication:** User login, registration, and protected routes.
- **Product Catalog:** Browse products by categories, brands, and search filters.
- **Shopping Cart & Wishlist:** Add, remove, and update product quantities dynamically.
- **Checkout & Orders:** Seamless checkout flow with form validation.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Form Handling & Validation:** React Hook Form & Zod
